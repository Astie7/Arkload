The engines of ArkLoad

====================

ArkLoad ships two engines next to the application.  They are separate programs: ArkLoad starts
them, drives them and stops them again, but it does not change them.

  JDownloader 2   the engine with the hosters, the link collectors and the plugins
  aria2           the small, fast downloader for the direct links

Both are driven through their own local interfaces (the local API of JDownloader 2, the JSON-RPC
interface of aria2).  ArkLoad picks the engine on its own - the user never chooses one.

Where they are
--------------

The installer puts them into

  %LOCALAPPDATA%\ArkLoad\engines

and the application looks for them there first, then in the folder of the program (a portable
copy) and then in the source tree (the development build).  A clean Windows system needs nothing
else: the Java runtime the JDownloader engine needs is part of the package.
